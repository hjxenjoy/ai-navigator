# 如何使用这份指南

## 这是为谁写的

这份指南是专门为**已经在用 AI 工具、但想真正掌控它**的工程师写的。

你的情况：
- 已经在用 Claude Code、Codex 或其他 AI Agent
- 用 AI 做了很多事，但有时候 AI 会失控，你不知道为什么
- 看 AI 的输出经常遇到看不懂的词汇
- 想在 AI 有限的能力范围内，创造真正的价值

## 学习路径：先走主线，再挑专题深入

这份指南是**"两遍读法"**设计的——第一遍把全貌走通，第二遍按需深挖，不用一上来就钻每个细节。

```
主线（建议按顺序走一遍）
  第0章 认知 ──▶ 第1章 LLM工程 ──▶ 第2章 构建产品 ──▶ 第4章 MCP/Agent ──▶ 第6章 提示词
                                                          │
想深挖了，再进 ↓                                          │
  ┌──────────────────────────────────────────────────────┘
  ├─ 第5章 四大专题深入：RAG / MCP / Skill / 微调（哪块用得上看哪块）
  └─ 4.7–4.9：AI 编程工作流 / Agent=Model+Harness / 上下文工程

可选（想懂原理再看）
  第3章 引擎盖下面：Transformer、Attention、训练、读论文
```

- **只想尽快上手**：主线走到第 2 章就能做出东西，提示词随时翻第 6 章。
- **某个主题要落地**（比如真要上 RAG / 写 MCP / 微调一个模型）：直接进第 5 章对应支线，里面是完整可跑代码 + 架构图 + 步骤。
- **想搞懂"为什么"**：第 3 章原理章是可选的，卡壳或好奇时再回头看。

## 阅读约定

- **💡 类比** — 用你熟悉的东西解释陌生的概念
- **⚠️ 常见误解** — 专门纠正容易理解错的地方
- **🛠️ 实践** — 可以动手做的练习或项目
- **📌 关键结论** — 最重要的判断，方便复习时快速提取
